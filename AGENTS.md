# dev-docs

Astro + Starlight site that republishes this repo's GitHub Wiki as a deployed docs site. The wiki is the only source of truth for content — never edit files under `src/content/docs/` directly, they're regenerated by the sync.

## Architecture

```
GitHub Wiki (gollum event / push to master)
        │  scripts/sync-wiki.mjs  — clones <repo>.wiki.git, needs git+GITHUB_TOKEN
        ▼
src/lib/wiki-convert.ts         — pure conversion: wiki pages + optional _Sidebar.md
        │                          → Astro content-collection entries + nav structure
        ▼
src/content/docs/, src/wiki-nav.json   (generated, gitignored)
        │  astro build
        ▼
Cloudflare Workers (wrangler deploy, gated by Cloudflare Access)
```

- **`scripts/sync-wiki.mjs`** — orchestration: clones the wiki repo, feeds pages to the conversion module, writes output. Does all network/git I/O. Not unit-tested — verify by running the workflow and checking the deployed site.
- **`src/lib/wiki-convert.ts`** — the conversion module, a pure seam (no I/O). Rewrites `[[Page Name]]` links to `/docs/Page-Name`, matching GitHub wiki's own slugify (spaces → hyphens, case preserved — no lowercasing). Builds nav from `_Sidebar.md` verbatim if present, else an alphabetical fallback, matching GitHub's own wiki behavior. This is the only unit-tested part of the pipeline (`wiki-convert.test.ts`) — the pure module is fast/reliable to test, the orchestration script isn't worth mocking.
- **`.github/workflows/wiki-sync.yml`** — triggers on `gollum` (wiki edit) and `push` to `master`; runs sync → `astro build` → `wrangler deploy`. Concurrency-grouped per event type with cancel-in-progress, to avoid piling up redundant deploys.
- **`src/content.config.ts`** — single `docs` collection using Starlight's stock loader/schema, no custom fields.

See [`CONTEXT.md`](./CONTEXT.md) for domain vocabulary.

## Commands

- `pnpm dev` / `pnpm build` / `pnpm preview` — standard Astro commands.
- `pnpm sync-wiki` — run the wiki sync locally (needs `GITHUB_TOKEN` and `GITHUB_REPOSITORY` env vars).
- `pnpm test` — runs `vitest`, covering only `wiki-convert.ts`.

## Development

Start the dev server in background mode:

```
astro dev --background
```

Manage it with `astro dev stop`, `astro dev status`, `astro dev logs`.
