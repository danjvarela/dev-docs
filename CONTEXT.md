# Domain Glossary

- **Wiki page**: a Markdown page from this repo's GitHub Wiki. Source of truth for all docs content — never edited directly in this repo.
- **Sidebar (`_Sidebar.md`)**: an optional wiki page that defines nav grouping/order. Absent → nav falls back to an alphabetical page list.
- **Conversion module**: the pure function/module that turns wiki pages (+ optional Sidebar) into Astro content-collection entries and a nav structure. No network or git I/O — the seam the tests target.
- **Orchestration script**: the glue that clones the wiki repo and hands pages to the conversion module, then triggers the Astro build. Not unit-tested; verified manually.
- **Docs collection**: the Starlight `docs` content collection in this repo that the conversion module's output populates.
- **Nav**: the sidebar/navigation structure Starlight renders, generated by the conversion module (verbatim from Sidebar, or alphabetical fallback).
